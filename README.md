# 🌐 Portfolio — Ahmed Yarhan Sulaiman

Website portofolio pribadi satu halaman (single-page), dibangun dengan HTML & CSS murni tanpa framework.

🔗 **Live:** [yarhansulaiman-star.github.io/portofolio](https://yarhansulaiman-star.github.io/portofolio/)

---

## ✨ Fitur

- 🎨 Desain dark-mode yang modern dengan aksen ungu
- 📱 Responsif untuk desktop & mobile
- ⚡ Ringan — satu file HTML, tanpa dependency
- 🅰️ Tipografi kustom (Space Mono & Syne)

---

## 📂 Struktur

```
portofolio/
└── index.html      # Seluruh halaman (HTML + CSS)
```

---

## 🚀 Menjalankan Secara Lokal

Cukup buka file `index.html` di browser, atau jalankan server lokal:

```bash
python -m http.server 8000
```

Lalu buka `http://localhost:8000`.
